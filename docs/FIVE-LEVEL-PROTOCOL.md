# Five-level development pilot

This extension preserves the canonical five objects: hypothesis, transition, trajectory, campaign and discovery.
Compilation, completion and readiness remain independent delivery metrics. Seven dimensions within a path/tree rubric do not create seven evaluation levels.

| Level | Object / coverage | Numerical output |
|---|---|---|
| Hypothesis | Each actual parent-child pair, blinded A/B metadata | (child wins + 0.5 ties) / assessable pairs; strict wins and abstentions also retained |
| Transition | Each derivation edge; all crossover parents available as context | Substantive / assessable; (substantive + necessary repair) / assessable; repetition and abstention separately |
| Trajectory | One deterministic longest-depth path per terminal node; singleton paths excluded | Original L1–L7 weighted profile, scope and review status retained |
| Campaign | Independent whole frozen graph | Original tree T1–T7 profile, reused from the campaign pilot; partial composites withheld |
| Discovery | All non-imported candidates partitioned into contribution families, then merged across datasets | Provisional consequential evidence-advance family count and count per 100 started episodes |

Hypothesis preference measures development relative to actual parents, not superiority against another system.
The transition contract has four original categories; it does not justify converting every repair into a scientific advance. It has no dedicated regression class: rationales retain such failures, and marginal_repetition should not be interpreted as a pure cosmetic-revision rate.
There are 142 EHR and 367 battery edge comparisons. The 30 imported EHR seeds remain context and opponents but are excluded from generated contribution counts.

## Scope and aggregation

Select paths from graph structure before any scores: longest depth to each leaf, lexical ID tie-breaking.
Clinical has 85 endpoint paths, 22 singletons; battery has 208 endpoint paths, 10 singletons.
Only 261 nontrivial paths are scored, not every alternative path at crossovers.
Shared ancestors make path/edge outcomes correlated.
The report provides descriptive rates and means without independence-based confidence intervals.

For a path, weighted points are sum(weight * score / 4).
Explicit rubric-permitted N/A dimensions can be removed from the denominator, with scope groups reported.
Unknown evidence is never converted to zero or removed to manufacture a complete score.
Complete composites and partial diagnostic profiles remain distinguishable.
The campaign is never computed by averaging hypothesis or path scores.

## Discovery qualification

A provisional evidence-advance family requires all three:
1. Reported diagnostic or stronger empirical evidence.
2. Model-assessed consequential importance.
3. Model-assessed increment beyond starting knowledge.

Question/proposal families below this threshold remain in the ledger.
Important negative or inconclusive findings can qualify; plans, synthetic fixtures and readiness passes alone cannot.
These are model-proposed groupings based on frozen evidence summaries, not independently confirmed scientific discoveries.
Independent novelty, truth, human rubric calibration and expert claim adjudication remain pending.
